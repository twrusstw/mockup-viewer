View shell demo

This file demonstrates the default view shell — body is wrapped in .workspace-leaf-content > .view-content, which inherits Obsidian's overflow: auto. Content longer than the viewport scrolls inside .view-content rather than being clipped.

Directives reference

  • <!-- as: modal --> — shell preset (see docs/directives.md)
  • <!-- host: my-class --> — class on shell's inner content element
  • <!-- viewport: mobile --> — preset (desktop/tablet/mobile) or 800x600
  • <!-- body-class: is-phone is-keyboard-open --> — extra body classes
  • <!-- styles: plugin:foo, vault:Mockup/draft.css --> — per-file source override
  • <!-- title: ... --> — display label

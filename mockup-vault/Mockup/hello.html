Hello, mockup

This is the minimal Mockup Viewer example.

Available directives (one per line at the very top of the file):

  • <!-- host: my-view-class --> — class added to iframe body so plugin selectors like .my-view-class .card match.
  • <!-- viewport: mobile --> — preset desktop, tablet, mobile or custom 800x600.
  • <!-- body-class: is-phone is-keyboard-open --> — extra classes on iframe body.
  • <!-- styles: plugin:foo, vault:Mockup/draft.css --> — override Settings sources for this file only.
  • <!-- title: ... --> — display label.

Charts: see with-chart.html. SVG icons: see with-svg.html.
